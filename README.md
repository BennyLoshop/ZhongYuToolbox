# 中育ToolBox 使用指南

## 项目简介

中育ToolBox 是一个便捷的中育账号资源管理工具，提供云笔记、在线专栏、错题本、随身答等多种功能的集成化Web应用。本工具与中育智慧（无锡）数字技术有限公司及其关联公司无关，仅供学习交流使用。

## 功能概览

- **用户登录**：支持多学校账号登录
- **云笔记管理**：浏览、搜索、下载和上传PDF笔记
- **图库管理**：上传、查看和管理图片资源
- **新测评**：查看和下载测评内容
- **在线专栏**：访问在线学习专栏
- **选课系统**：课程选择和管理
- **错题本**：查看和管理错题
- **随身答**：问答交流和画板回复
- **应用下载**：下载中育相关应用
- **优客畅学**：在线学习平台
- **开发工具**：OSS文件上传等开发功能
- **下载加速**：本地代理加速插件

## 详细使用指南

### 1. 用户登录

**功能说明**：首次使用需要登录您的中育账号。

**操作步骤**：
1. 打开页面后，默认显示登录界面
2. 选择您的学校（默认：省锡中，可选：其它学校）
3. 如果选择"其它学校"，需要输入学校代码
4. 输入用户名和密码
5. 点击"登录"按钮

**注意事项**：
- Token会自动保存在本地，有效期内无需重复登录
- 如果Token过期，系统会提示重新登录
- 可以在"高级选项"中查看和复制Token

### 2. 云笔记

**功能说明**：浏览、搜索、下载和管理您的云笔记。

**主要功能**：

#### 2.1 文件夹视图
- 点击"文件夹"标签查看笔记目录结构
- 使用面包屑导航切换目录
- 点击笔记可下载图片压缩包

#### 2.2 全部笔记
- 点击"全部笔记"标签查看所有笔记
- 支持分页浏览

#### 2.3 搜索笔记
- 点击"搜索"标签
- 输入笔记名称关键字
- 点击"搜索"按钮或按Enter键
- 支持分页显示搜索结果

#### 2.4 PDF上传云笔记
- 点击"PDF上传"标签
- 输入笔记名称（会自动填充PDF文件名）
- 选择要上传的PDF文件
- 点击"开始上传"按钮
- 系统会自动将PDF转换为图片并上传到云笔记

**PDF上传流程**：
1. 选择PDF文件后，系统会显示文件信息
2. 点击"开始上传"后，系统会：
   - 调用服务端接口将PDF转换为WebP图片
   - 将图片上传到阿里云OSS
   - 保存笔记资源信息
3. 上传进度会实时显示在进度条中
4. 上传完成后会显示成功提示

### 3. 图库

**功能说明**：管理您的图片资源。

**操作步骤**：
1. 点击左侧菜单"图库"
2. 默认显示"正常图片"标签页
3. 点击"上传图片"按钮选择并上传图片
4. 可以切换到"回收站"查看已删除的图片

**功能特点**：
- 支持分页浏览
- 点击"查看"按钮在新窗口打开图片
- 上传的图片会自动生成缩略图

### 4. 新测评

**功能说明**：查看和下载测评内容。

**操作步骤**：
1. 点击左侧菜单"新测评"
2. 系统会加载测评列表
3. 点击测评项查看详情
4. 在详情页面可以下载相关内容

### 5. 在线专栏

**功能说明**：访问在线学习专栏内容。

**操作步骤**：
1. 点击左侧菜单"在线专栏"
2. 页面会加载在线专栏内容
3. 点击"在新页面打开"可以在独立窗口中查看

### 6. 选课

**功能说明**：进行课程选择和管理。

**操作步骤**：
1. 点击左侧菜单"选课"
2. 页面会加载选课系统
3. 按照系统提示进行课程选择

### 7. 错题本

**功能说明**：查看和管理您的错题。

**操作步骤**：
1. 点击左侧菜单"错题本"
2. 选择学科（语文、数学、外语等）
3. 系统会加载对应学科的错题列表
4. 点击错题可以查看详情，包括：
   - 题目
   - 答案
   - 解析
   - 笔记
   - 图片笔记

### 8. 随身答

**功能说明**：进行问答交流，支持画板回复。

**主要功能**：

#### 8.1 搜索问题
- 输入关键词搜索问题
- 选择学科进行筛选
- 使用高级筛选设置发布时间、更新时间等条件

#### 8.2 查看问题详情
- 点击问题卡片查看详情
- 可以下载问题相关的图片资源

#### 8.3 画板回复
- 在问题详情页面点击"回复"按钮
- 打开画板回复界面
- 功能包括：
  - 选择/移动工具
  - 画笔工具（支持调整颜色和粗细）
  - 文字工具
  - 插入图片
  - 撤销/重做
  - 删除/清空
  - 背景颜色选择
  - 缩放控制
- 编辑完成后点击"发送"提交回复

### 9. 下载应用

**功能说明**：下载中育相关应用。

**可用应用**：
- 云笔记（平板应用）
- 新测评（平板应用）
- 优客畅学（平板应用）
- 用户中心（平板应用）
- 错题本（平板应用）
- 在线专栏（平板应用）
- 随身答（平板应用）
- 中育教师端（平板应用）
- 中育课堂助手（PC应用）

**操作步骤**：
1. 点击左侧菜单"下载应用"
2. 找到需要下载的应用
3. 点击"下载"按钮
4. 如果下载失败，点击"刷新"按钮后重试

**注意事项**：
- 未经授权在其他设备登录可能导致账号被封禁
- 本页面仅提供应用下载，不保证可以在所有设备上运行

### 10. 优客畅学

**功能说明**：访问优客畅学在线学习平台。

**操作步骤**：
1. 点击左侧菜单"优客畅学"
2. 点击"更换课程"选择要学习的课程
3. 在课程列表中选择章节
4. 点击"手动渲染"如果视频无法播放或渲染异常
5. 可以点击"下载源文件"保存课程内容

**功能特点**：
- 支持课程搜索
- 显示课程ID和章节ID
- 支持分享课程（需要选择章节）

### 11. 高级选项

**功能说明**：提供高级功能和开发者选项。

**主要功能**：
- 查看账号Token
- 刷新Token
- 复制Token
- 查看课表
- 网阅联考
- 启用iframe预览（开发者选项）
- 启用优客畅学（默认启用）

**注意事项**：
- 高级选项使用不当可能造成损失，请谨慎操作
- Token是敏感信息，请勿泄露

### 12. 开发工具

**功能说明**：提供开发相关的工具功能。

**主要功能**：
- 上传文件到中育OSS
- 支持多种上传类型（note_v2、eval_v2、quora_v2等）
- 自定义上传路径和文件名

**操作步骤**：
1. 选择上传类型
2. 系统会自动生成上传路径
3. 可以自定义nonce和文件名
4. 选择要上传的文件
5. 点击"上传"按钮

### 13. 下载加速插件

**功能说明**：下载并安装本地代理加速插件，提升资源加载速度。

**加速插件**：
- Windows版：tbHelperInstaller.exe
- 安卓版：tbHelper.apk

**使用方法**：
1. 点击左侧菜单"下载加速插件"
2. 根据您的系统选择对应版本下载
3. 安装并运行加速插件
4. 系统会自动检测加速插件状态

**功能特点**：
- 不使用加速插件不会影响正常使用
- 系统会自动检测加速插件是否运行
- 检测到加速插件后会显示提示信息

## 分享功能

### 创建分享
1. 在支持分享的功能页面，点击分享按钮（📤图标）
2. 填写分享信息：
   - 资源类型（自动填充）
   - 标题（给分享起个名字）
   - 访问密码（可选）
   - 过期时间（小时，0=永久）
   - 最大查看次数（0=不限）
3. 点击"生成分享链接"
4. 复制生成的分享链接

### 查看分享
- 通过分享链接访问分享内容
- 如果设置了密码，需要输入密码才能查看

## 常见问题

### 1. 无法登录
- 检查用户名和密码是否正确
- 确认选择的学校是否正确
- 如果选择"其它学校"，确认学校代码是否正确

### 2. 图片/资源加载慢
- 建议下载并安装加速插件
- 检查网络连接是否正常

### 3. PDF上传失败
- 确认PDF文件是否损坏
- 检查网络连接
- 查看浏览器控制台错误信息

### 4. 画板功能无法使用
- 确认浏览器支持Canvas
- 尝试刷新页面
- 检查JavaScript是否启用

### 5. 应用无法下载
- 点击"刷新"按钮后重试
- 检查网络连接
- 确认下载链接是否有效
